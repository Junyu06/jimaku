# Keep the session captions in memory only

The captions of the current session are held in memory and listed in the app. Starting a new session clears them. Nothing is written to disk.

Why: the list exists so the reader can look back during or right after watching. Keeping captions across sessions would need a history screen and a way to delete it, which the first version does not have.

Cost accepted: captions are gone when the app is closed or a new session starts.
