# cases/

Each file here states: **input I must produce observable result O, proving property P.**

Files are named `<area>-<nnn>-<proposition>` and carry frontmatter with `area` and `status`. Status is one of `passed`, `failed`, `simulated`, `not-run`. A case run only in the simulator is `simulated`; it becomes `passed` only with evidence from a physical device.
